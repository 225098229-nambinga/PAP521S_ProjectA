## 2. Project Description

The Municipal Financial Management System (MFMS) is a menu-driven C
application developed as Project A for PAP521S – Programming in Practice
at the Namibia University of Science and Technology (NUST).

The purpose of Project A is to deliver the foundation version of a system
that a municipality could use to manage its core administrative and
financial information.

The system is built entirely in C and applies the programming concepts
covered in Weeks 1–8 of the course:

- Variables and data types
- Input and output
- Arithmetic, relational and logical operators
- Decision-making (if, if-else, switch)
- Loops (for, while, do…while)
- Arrays
- Strings and standard string functions
- Functions (declarations, definitions, parameters, return values)

The system is intentionally modular — each major area of the municipality
is implemented as its own module with its own source and header file.
This makes the code easier to read, test, maintain, and extend in Project B.

Project A follows the flow:

> INPUT → PROCESSING → STORAGE → SEARCH → CALCULATION → OUTPUT

## 3. System Features

The MFMS is divided into the following modules:

### 3.1 Main Menu
A menu-driven interface providing access to:

1. Employee Management
2. Budget Management
3. Supplier Management
4. Asset Management
5. Reports
0. Exit

### 3.2 Employee Management
Add, display, and search employee records. Calculate total salary from
basic salary, housing allowance, and transport allowance.

### 3.3 Budget Management
Add departmental budgets and expenditures. Calculate remaining budget and
detect departments that exceed their allocation.

### 3.4 Supplier Management
Add, display, search, and compare suppliers. Includes input validation for
supplier ID, email, and phone number.

### 3.5 Asset Management
Register municipal assets (vehicles, computers, equipment, etc.) with
purchase value, department and condition.

### 3.6 Reports
Generate employee, budget, supplier and asset reports with totals,
averages, highest/lowest values and department summaries.
